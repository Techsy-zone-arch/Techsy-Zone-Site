# ⚡ TechsyZone - منصة وساطة ومتجر الحواسيب واللابتوبات الاحترافية

منصة تجارة إلكترونية ووساطة تقنية متكاملة ومستقلة، مخصصة لبيع وعرض أجهزة اللابتوب، الحواسيب المجمعة، الشاشات، وقطع الهاردوير مع ربط مباشر بين المشترين والمتاجر الشريكة المعتمدة بنسبة عمولة 0% إضافية على المشتري.

---

## 🚀 دليل التشغيل والرفع المباشر على Render و GitHub

المشروع مهيأ بالكامل للرفع على **GitHub** والنشر الفوري على استضافة **Render** دون أي مشاكل في البناء أو الصور أو التنسيقات.

### الطريقة الأولى: النشر التلقائي عبر ملف Blueprint (`render.yaml`) (موصى بها)
1. قم بإنشاء مستودع جديد على **GitHub** ورفع ملفات المشروع إليه:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - TechsyZone Store"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/techsyzone.git
   git push -u origin main
   ```
2. ادخل إلى حسابك في موقع [Render Dashboard](https://dashboard.render.com).
3. اضغط على **New +** ثم اختر **Blueprint**.
4. اربط مستودع GitHub الخاص بك؛ سيتعرف Render تلقائياً على ملف `render.yaml` المرفق ويضبط الإعدادات ذاتياً.
5. اضغط **Apply** وسيبدأ النشر تلقائياً.

---

### الطريقة الثانية: النشر اليدوي كـ Web Service على Render
1. من لوحة Render اضغط **New +** ثم **Web Service**.
2. اختر مستودع المشروع من GitHub.
3. اضبط الإعدادات التالية بدقة:
   - **Name**: `techsyzone`
   - **Environment / Runtime**: `Node`
   - **Region**: `Frankfurt` (أو أي منطقة قريبة)
   - **Branch**: `main`
   - **Build Command**:
     ```bash
     npm install && npm run build
     ```
   - **Start Command**:
     ```bash
     npm start
     ```
   - **Plan**: `Free`
4. في قسم **Environment Variables** (المتغيرات البيئية):
   - أضف المتغير: `NODE_ENV` بقيمة `production`
   - أضف المتغير: `PORT` بقيمة `10000`
5. اضغط **Create Web Service**، وخلال دقيقة واحدة سيكون موقعك نشطاً ويعمل أونلاين على نطاق `https://techsyzone.onrender.com`.

## 🛠️ أوامر التطوير والتشغيل المحلي (Local Development)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر المحلي في وضع التطوير (Port 3000)
npm run dev

# 3. بناء المشروع للإنتاج وتجهيز الحزم
npm run build

# 4. تشغيل خادم الإنتاج

```

## 🔐 رابط لوحة تحكم المدير المستقلة (Admin Dashboard)

حفاظاً على خصوصية واجهة الزبائن، تم فصل صفحة الإدارة تماماً لتكون على رابط مستقل خاص:
- **رابط الإدارة**: `https://your-domain.onrender.com/administrationlink`
- **الرمز السري الافتراضي للمدير**: `admin123` (أو `techsy2026`)

### 🎛️ مميزات لوحة تحكم المدير:
1. **رفع الشعار والأيقونة**: إمكانية رفع صورة شعار من جهازك وحفظها فورياً كشعار للمتجر وشاشة البداية.
2. **محرر الواجهة الحي المباشر (Live Visual Editor - WYSIWYG)**: زر تفعيل يتيح لك تعديل العناوين والنصوص والألوان والأرقام مباشرة من الواجهة مع حفظها أونلاين.
3. **التخزين الاحتياطي السحابي (Google Drive)**: خانة لتحديد بريد غوغل درايف المستهدف مع زر مزامنة وتصدير احتياطي فوري لحماية السيرفر من امتلاء مساحة الاستضافة.
4. **أرقام التواصل والطلبات**: تعديل رقم الواتساب ورابط المسنجر وحسابات الفيسبوك والانستغرام.
5. **إدارة المنتجات والمتاجر**: إضافة وتعديل وحذف الأجهزة وتحديد نسب العمولة المخصومة من أرباح المتجر.
6. **إدارة الطلبات وسجل المشتريات**: اعتماد فواتير الشراء، وطباعة الفواتير الرسمية، وحذف أي طلب.
7. **نظام نشرة السبت التلقائية**: استعراض المشتركين المشفرين، إرسال النشرة الأسبوعية بضغطة زر، وإمكانية حذف أي مشترك.

## 👥 مميزات واجهة الزبائن
- شاشة بداية ترحيبية متناسقة تتلاشى تدريجياً.
- شاشة تحميل ذكية عند مزامنة السيرفر: *"يرجى الانتظار جاري التحميل..."*.
- زر تواصل وطلب فوري عبر **الواتساب** أو **المسنجر**.
- روابط مباشرة لصفحة الفيسبوك وحساب الانستغرام.
- سجل مشتريات خاص بالزبون مع:
  - زر **«تم الاستلام»** لإشعار الإدارة وتحصيل عمولة الوساطة.
  - زر **«إلغاء الطلب (واتساب)»** الذي يرسل رسالة فورية لرقم واتساب الفريق لإيقاف التجهيز.
  - زر **«حذف من سجلي»**.
- وضوح فائق للخطوط بالوضع النهاري (ألوان داكنة وعالية التباين) والوضع الليلي (ألوان ناصعة ومضيئة).
